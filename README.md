# Scoreboard Counter

This is a simple basketball scoreboard application that allows users to track scores for two teams: **Home** and **Guest**. The scores update dynamically when users click the +1, +2, or +3 buttons. The team with the higher score is highlighted in green, while the other team is styled in red.

## Features
- Home and Guest score tracking
- Clickable buttons to increase scores by 1, 2, or 3 points
- Dynamic color change to indicate which team is winning
- Responsive design with a stylish UI

## Technologies Used
- **HTML** - Structure of the scoreboard
- **CSS** - Styling and layout
- **JavaScript** - Handles score updates and color changes dynamically

## How to Use
1. Click the `+1`, `+2`, or `+3` button under **Home** or **Guest** to increase the score.
2. The team with the higher score turns green, while the losing team turns red.
3. If both teams have the same score, they remain in the default color.
